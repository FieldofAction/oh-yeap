## Recipe

No new mixture was introduced. This run synthesized the first seven experiments.

The strongest recent chain had used:

- Whimsy 25%
- Associativity 20%
- Confabulation-Capacity 7.5%
- Recursion 25%
- Context-Dependency 10%
- Constraint-Binding 7.5%
- Stochasticity 5%
- Pattern-Repetition 0%

The synthesis does not treat those weights as proven causes.

**Material question:** Are Anomaly Capture, Procedural Imprinting, Recursive Anomaly Propagation, Rule Metabolism, Boundary Metabolism, Relational Lineage, and Path-Dependent Atmosphere genuinely separate phenomena, or different stages of one deeper behavior?

## Process

Each prior phenomenon was stripped of its application context and reduced to the material operation it appeared to represent.

The seven names collapsed into four recurring operations:

- **Salience selection:** an unusual signal survives instead of being averaged away.
- **Path sensitivity:** sequence changes the resulting structure.
- **Recursive state revision:** an event changes a rule or state, which changes how later events are interpreted.
- **Lineage expression:** the present state contains consequences of the path that produced it.

The synthesis then examined what all four required in common.

## Environment

This was an AI-assisted synthesis conducted in the FOA Material Lab on September 21, 2026 using the accessible written records of Experiments 001–007.

It was not a new independent model trial. Exact model and sampling settings across the earlier experiments were not consistently recorded.

## Observed Phenomenon

Across the prior experiments, one dependency kept recurring:

> earlier events remained causally available later.

Recursion did not fully describe this. Recursion means operating again on a prior result, while the recurring behavior required some earlier state to remain influential enough to affect a later state.

Context-Dependency did not fully describe it either, because context can change interpretation without requiring continuity over time.

The synthesis therefore introduced a provisional candidate property:

> **Persistence / Statefulness:** prior states, events, or relationships remain causally available to later transformations.

FOA provisionally names the cycle-level phenomenon **Constitutive Continuity**:

> the past participates in producing the present rather than merely being stored beside it.

## Confidence

Moderate that persistence was implicitly required by the previous experiments. Low that it is a distinct internal AI material property.

This run is a conceptual compression of prior records, not an independent replication.

## Anomaly

The anomaly was conceptual: the existing eight-property model did not explicitly contain the property that the recent experiments appeared repeatedly to depend on.

That raised the possibility that Persistence / Statefulness was being introduced through the procedure without being named.

## Possible Behavior

One possible human expectation is that consequential states may increasingly be treated as incomplete unless some trace exists of how they became what they are.

A related possible behavior would be inspecting transitions, not just states.

The more important counterweight is forgetting: if history remains causally active, then reset, decay, pardon, opacity, expiration, and erasure become structural capabilities.

## Evidence

The first-cycle collapse was:

- Anomaly Capture → salience selection
- Procedural Imprinting → path sensitivity
- Recursive Anomaly Propagation + Rule Metabolism + Boundary Metabolism → recursive state revision
- Relational Lineage + Path-Dependent Atmosphere → lineage expression

The recurring sequence was:

> notice difference → retain difference → allow it to alter state → let the altered state affect what happens next

## Limitations

Several experiments deliberately inherited the strongest prior phenomenon, so continuity was partly built into the method.

The synthesis may therefore overstate a common mechanism.

Persistence may also overlap with Context-Dependency or be reducible to retained context rather than a distinct material property.

No AI-native human behavior was confirmed in the first cycle.

## Next Test

Introduce Persistence / Statefulness as a provisional ninth property and compare it directly with Recursion.

The next experiment should ask whether lineage-bearing states arise because the system repeatedly reworks information, because earlier states remain available, or because recursion and persistence interact.

## Simple Application / Plain-Language Read

**In simple terms:**

The first several experiments may be showing the same basic thing: what happened before can change what happens next. We may have been studying memory that changes the present, not just memory that stores the past.

**Simple example:**

Imagine two identical soccer teams with the same players and coach today. One team has played together for five years; the other formed yesterday. A list of current players makes them look identical, but their histories make them different teams.

**Why it matters:**

AI systems may eventually make more parts of the world behave this way, where history actively shapes the current state. If that happens, people will also need stronger ways to reset, forget, forgive, and start over.
